# Pomodoro 番茄钟

这是一个基于 Python Tkinter 的简单番茄钟应用。它可以帮助你进行专注工作和休息的时间管理，支持自定义工作时长与休息时长，并在一个番茄钟完成后自动切换状态。

## 功能

- 设置工作时长（默认 25 分钟）
- 设置休息时长（默认 5 分钟）
- 开始、暂停、重置计时
- 自动完成工作后切换到休息
- 统计今日完成的番茄数量
- 结束时播放提示音

## 运行环境

- Python 3
- Windows 系统（因为使用了 `winsound` 播放声音）
- Tkinter 库（通常随 Python 一起安装）

## 运行方法

1. 打开终端并切换到项目目录：
   ```bash
   cd C:\Users\Administrator\Desktop\pomodoro
   ```

2. 运行脚本：
   ```bash
   python pomodoro.py
   ```

## 使用说明

1. 启动后，默认显示 `25:00`。
2. 点击“开始”开始工作计时。
3. 点击“暂停”可以暂停当前计时。
4. 点击“重置”可以恢复到初始工作时长。
5. 工作计时结束后会自动进入休息计时；休息结束后会回到准备状态。

## 备注

- 如果你希望在其他系统上运行，需要将 `winsound` 播放音效部分改为跨平台方案，例如 `pygame` 或 `playsound`。
- `README.md` 适合直接放在仓库根目录，便于在 GitHub 上展示项目说明。
